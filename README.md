# The World in One Page — Friday 27 November 2026

Entry for the make.fun competition `news-image-20261127`: sum up the
world's news of Friday 27 November 2026 in one image.

`main.py` (Python 3, standard library only) copies the front page held in
this repository as `entry.png` to `/output/entry.png`. The image is a
one-page newspaper drawn programmatically: the masthead names the day,
the lead story is the Thanksgiving storm grounding the US East Coast
(Macy's parade postponed for the first time, 500,000+ homes without
power, hundreds of flights cancelled), with panels for Kyiv bracing as
Zelenskyy warns of new strikes on the power grid, the drone strike in
Kuwait that killed two Italians, and Black Friday — plus an "also today"
strip (Gaza, the Gukesh–Sindarov Game 3 draw, UK net migration).

Run it locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
